# Mobile Web / PWA

The game is now PWA-ready. It can be installed to the home screen when hosted on `https://` or `localhost`.

## Local Test

1. Double-click `play-game.cmd`.
2. Open `http://127.0.0.1:5173` if it does not open automatically.
3. In a desktop browser, use the install button in the address bar.

## Phone On Same Wi-Fi

1. Double-click `start-phone-game.cmd`.
2. Keep the command window open.
3. Use the printed `http://<LAN-IP>:5173` address in your phone browser.

## Shareable Link

To send a link that works for anyone anywhere, deploy this folder to an HTTPS static host such as Netlify, Vercel, or GitHub Pages.
